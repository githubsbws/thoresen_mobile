**วิธีติดตั้งโปรเจกต์ThorConn** 
*สิ่งที่ต้องติดตั้งก่อน (Prerequisites)* 

ก่อนเริ่มใช้งงานโปรเจกต์ กรุณาติดตั้งโปรแกรมต่อไปนี้ให้เรียบร้อย

Node.js (เวอร์ชัน 18ขึ้นไป)
npmหรือyarn  (ติดตั้งมาพร้อมกับ NOde.js)
Expo SDK : 54
React : 19.1.0
React : 0.81.5
Expo Router : 6.x
JDK17
EXpo Go app บนมือถือ
**ต้องมี**

**ขั้นตอนที่ 1 clone  โปรเจกต์จาก GitHub**
git clone (https://github.com/ชื่อusername/thorconn)
 
**ขั้นตอนที่ 2 เข้าไปยังโฟล์เดอร์ของโปรเจกต์**
ใช้คพสั่ง
 cd thorconn

**ขั้นตอนที่ 3 เริ่มต้อนการรันโปรเจกต์**
รันคำสั่งต่อไปนี้
  npm install ใน Terminal ระบบจะติดตั้ง Package ทั้งหมดที่อยู่ใน package.json โดยอัตโนมัติ

**ขั้นตอนที่ 4 เริ่มต้นการรันโปรเจกต์**
เมื่อการติดตั้ง Package เสร็จเรียบร้อย ให้รันคำสั่ง

npx expo start 

เมื่อระบบทำงานสำเสร็จ จะปรากฏ QR Code บนหน้าต่าง Terminal 
จากนั้นสแกน QR Code เพื่อเปิดแอปเปิดใช้งาน แอปพลิเคชั่น 
หากทุกขั้นตอนถูกต้อง แอปพลิเคชันจะสามรถเปิดใช้งานได้ตามปกติ
